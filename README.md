# Dekati Knowledge Assistant (prototype)

A retrieval-augmented question-answering system over Dekati Ltd's internal
documents, built for the Master's thesis *"AI-Powered Retrieval-Augmented
Generation System for Dekati Ltd"* (University of Vaasa, 2026).

Ask a question in plain language; the system finds the relevant passages in
the company documents and a local language model answers **only from those
passages**, citing them as sources. Everything runs locally: no company data
is sent to external services.

> **Confidential data is not in this repository.** The `data/` folder (raw
> files, extracted text, chunks, vectors, indexes) is excluded by `.gitignore`.
> The code works on any corpus with the same structure.

## Pipeline

```
raw files ─▶ readers + OCR ─▶ normaliser ─▶ token chunker ─▶ embeddings ─▶ indexes ─▶ hybrid search ─▶ answer
            src/data_readers  src/normalizer  token_chunking  vectorization  build_index  search.py      rag/ask.py
                                                                             build_multilingual_index      ui/app.py
```

| Stage | Script | Output (in `data/processed/`) |
|---|---|---|
| Extract | `src/data_readers/*_reader.py` | `<type>/*_extracted_documents.json` |
| Normalise | `src/normalizer/from_*.py` | `normalized/*_normalized.json` |
| Chunk (max 204 tokens, nothing dropped) | `src/data_processing/token_chunking.py` | `chunked/chunks.jsonl` + meta |
| Embed (all-MiniLM-L6-v2, prose-like chunks) | `src/data_processing/vectorization.py` | `vectors/embeddings.npy`, `row_ids.npy` |
| Index (SQLite + BM25 for all chunks, FAISS for vectors) | `src/retrieval/build_index.py` | `index/` |
| Finnish index (multilingual-e5-small) | `src/retrieval/build_multilingual_index.py` | `index_multilingual/` |
| Search (FAISS + BM25 + multilingual, RRF) | `src/retrieval/search.py` | – |
| Answer (Ollama, local) | `src/rag/ask.py` | – |
| Web interface | `src/ui/app.py` | – |

Every stage writes to temporary files first and only renames them after its
checks pass; nothing is ever overwritten.

## Setup

```bash
conda create -n dekati-ai python=3.11
conda activate dekati-ai
pip install -r requirements.txt

# local language model
brew install ollama          # or download from https://ollama.com
ollama pull llama3.2:3b
```

## Run

With the indexes already built:

```bash
python src/ui/app.py
```

Then open **http://localhost:8000** in a browser (only reachable from this
computer). The answer test bench is at **http://localhost:8000/test**.

From the command line:

```bash
python src/rag/ask.py "What are the technical specifications of the DOFR?"
python src/retrieval/search.py "heated sampling line temperature"    # sources only
```

## Rebuilding from normalised data

```bash
python src/data_processing/token_chunking.py          # ~1.5 h
python src/data_processing/vectorization.py           # ~4.5 h, resumable (Ctrl+C safe)
python src/retrieval/build_index.py                   # ~5 min
python src/retrieval/build_multilingual_index.py      # ~20 min
python src/tools/check_index_coverage.py              # verifies every chunk is reachable
```

Each script refuses to run if its output already exists; move old outputs
away first.

## Tests and checks

```bash
python tests/test_token_chunking.py        # 31 tests on synthetic text
python src/tools/data_stats.py             # numbers-only overview of data/
```

Scripts that read the real corpus print **only aggregate numbers** (counts,
sizes, PASS/FAIL), never document text or file names.

## Evaluation

```bash
python src/evaluation/run_evaluation.py               # writes review sheets into data/evaluation/
python src/evaluation/score_evaluation.py data/evaluation/run_<timestamp>
```

The question files (`evaluation/questions.json` and
`evaluation/questions_usecases.json`) are not included in this repository.
Options: `--model qwen2.5:3b` to answer with Qwen instead of Llama, and
`--mode advisor` for answers with facts plus suggestions.

```bash
python src/evaluation/make_comparison_page.py --pair RUN_A RUN_B   # side-by-side rating page
python src/evaluation/score_comparison.py ratings.csv              # scores from the downloaded ratings
```

## Thesis

The thesis itself is not included in this repository. Its measured numbers
are generated by `python src/tools/thesis_numbers.py`.

## Hardware used

Intel MacBook Pro, 8 GB RAM, no GPU. Answers take roughly 30–120 s on this
machine; the web page streams the answer as it is written.
